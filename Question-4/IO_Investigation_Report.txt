TECHNICAL OBSERVATIONS

Linux manages file input and output using file descriptors.
File descriptor 0 represents standard input, 1 represents standard output, and 2 represents standard error.
In this experiment, file descriptor 3 was manually opened and connected to app.log.
The > operator redirected standard output, while 2> redirected error output to a separate file.
The /proc/$$/fd directory provided information about file descriptors opened by the current shell.
